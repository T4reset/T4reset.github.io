# GuíaPráctica — prototipo

Web estática preparada para evolucionar hacia una web editorial de comparativas y guías.

## Archivos
- index.html
- style.css
- script.js

## Próximo paso
1. Cambiar nombre/marca cuando tengamos decidido el proyecto.
2. Escribir las 10 primeras publicaciones completas y originales.
3. Añadir páginas legales (privacidad, cookies/consentimiento según corresponda, aviso legal y afiliación).
4. Publicarla en GitHub Pages.
5. Conseguir tráfico inicial.
6. Solicitar Amazon Afiliados cuando el sitio cumpla los requisitos.

Importante: no añadir enlaces de afiliado de Amazon hasta tener claro que la web cumple sus políticas y la cuenta correspondiente.
