# Checklist abans de publicar

1. Completar les dades reals del titular a les pàgines legals.
2. Revisar la disponibilitat del domini i la marca abans d'un ús comercial.
3. Completar 10 publicacions originals abans de sol·licitar afiliació, seguint els requisits vigents d'Amazon.
4. Revisar les polítiques d'Amazon abans d'afegir enllaços.
5. Publicar la web i comprovar tots els enllaços.
